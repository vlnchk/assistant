# dev/ — как мы работаем

Процессный слой. Описание системы «как есть» — в `../README.md` и `../prd/`.

| Файл | Отвечает на вопрос | Частота изменений |
|---|---|---|
| [STATUS.md](STATUS.md) | На чём остановились | каждую сессию |
| [ROADMAP.md](ROADMAP.md) | Что делаем дальше | редко, обсуждается |
| [decisions/](decisions/) | Почему так решили | при каждом решении |
| [findings/](findings/) | Чем доказан баг | при каждом инциденте |

Инварианты и команды — в `../AGENT.md`, он загружается агентом автоматически.

## Откуда это взялось

До 18.09.2026 всё перечисленное жило в одном файле
`prd/improvements_backlog.md`: решения, доказательства, план, статус и
отчёты о верификации вперемешку, 26 КБ. Последствия были не теоретические —
решение «две опции на любую вакансию» было принято и не реализовано, и
разрыв никто не заметил, пока не понадобился аудит.

Файл расселён и удалён 19.09.2026. Закрытые пункты, покрытые тестами
(D2, P1, P3.1, P3.2, исторические прогоны евалов), сознательно оставлены
в истории git:

```bash
git log --diff-filter=D -- prd/improvements_backlog.md
git show <коммит>^:prd/improvements_backlog.md
```
