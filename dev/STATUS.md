## Следующий шаг

**Выкатить M2 + M3 + M4 одним деплоем** — вместе с новой ценой ОРД
(1 500 ₽ вместо 2 000 ₽) и очисткой цен из подсказок модели. По частям нельзя:

- M3 без M2 утягивает больше клиентов в сломанную воронку (ADR-0004);
- M2 без M4 вносит новый баг: июльская вакансия перехватывает сентябрьский
  вопрос о рекламе (ADR-0008).

Деплой строго по `README.md`, раздел «Обновление бота на VPS». **Впервые за
арку деплой содержит миграцию БД** (`fdcc4873908b`, добавляет колонку
`admin_topics.escalated_at`). Контейнер применяет её при старте, поэтому
бэкап на шаге 0 обязателен. Миграция только добавляющая и проверена на
копии базы в обе стороны.

**Проверка после деплоя — по `prd/manual_test_scenarios.md`, сценарии 48–60.**
Они покрывают всё новое: две опции на вакансию, воронку платной вакансии,
прод-дефект 09.09.2026 (сценарий 51), анти-регресс календаря для рекламы,
новую цену ОРД, границу сессии и напоминание менеджеру. Два последних
завязаны на время, поэтому для них в файле есть SQL-рецепт сдвига времени
на тестовом аккаунте — проверен на копии базы.

После выката — выбрать следующий майлстоун из кандидатов роадмапа. Первый
с доказанной нуждой — `/close-milestone`.

## Чего ждём от человека

Деплоя. Доступа к VPS из сессии нет.

После деплоя стоит проверить одну вещь руками: зависшие в `waiting_human`
клиенты, если они есть, при первом же сообщении получат «Менеджер пока не
ответил — я напомнил ему ещё раз», а в теме эскалаций появится повторное
оповещение. Это ожидаемо (ADR-0009), а не сбой.
