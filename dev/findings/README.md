# Находки (findings)

Воспроизведённые прод-инциденты с доказательствами. Один файл — один дефект.

**Что сюда идёт:** дефект, который наблюдали в реальном диалоге и сумели
воспроизвести командой. Обязательны: исходный диалог, команда воспроизведения,
результат прогонов, механизм, ссылка на закрывающий ADR.

**Что сюда НЕ идёт:** наблюдения из ревью кода без прод-симптома (мёртвый код,
отсутствие таймаутов, технический долг) — это строки в `../ROADMAP.md`.
Мнения и гипотезы — тоже мимо: находка это факт с командой воспроизведения.

**Почему отдельно от ADR:** доказательство и решение живут по-разному.
Факт «воспроизвёл 3/3, вот команда» не устаревает никогда. Решение на его
основе может быть заменено следующим ADR.

**Статус находки** отражает дефект, а не работу: `воспроизведено` →
`закрыто в <коммит>`. Закрытую находку не удаляем — она остаётся защитой от
повторного внесения того же дефекта.

- `2026-09-17-repro-probes.jsonl` — зонды, отделяющие «нет инструмента»

Прогон (dry-run, в Google Sheets не пишет):

```

  --dataset dev/findings/2026-09-17-repro.jsonl --no-metrics
```

должен. Ожидания появятся в `tests/fixtures/dialog_cases.jsonl` на M0.
