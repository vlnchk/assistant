# ADR-0001. LLM — только роутер, тексты клиенту только из `bot/replies.py`

- **Дата:** 10.06.2026 (записано задним числом 18.09.2026)
- **Статус:** реализовано в `fea3af9`

## Контекст

Бот называет клиентам цены, условия и ссылки на форму. Любая свободная
генерация текста моделью — это риск назвать несуществующую цену или выдумать
ссылку, причём незаметно: ошибка выглядит как нормальный ответ.

## Решение

Модель не имеет канала для свободного текста. Она обязана вызвать ровно один
зарегистрированный инструмент (`FunctionCallingConfigMode.ANY`), а клиенту
уходит константа из `bot/replies.py` — дословно, максимум с `.format()`.
Свободный текст модели без вызова функции считается ошибкой маршрутизации
и клиенту не отправляется.

## Последствия

- Бот не может соврать про цену. Может привести не тот текст — это и есть
  класс ошибок, который мы ловим (см. `findings/`), и он несравнимо дешевле.
- Формулировки правятся в одном файле без редеплоя промпта.
- Цена: бот не умеет здороваться и отвечать на вопрос одной репликой,
  не умеет переформулировать под контекст. Принято сознательно.
- Новый продукт = новый инструмент. Без инструмента модель возьмёт ближайший
  существующий — механизм инцидента от 17.09.2026.

## Альтернативы, которые отвергли

- **Генерация ответа моделью по RAG-контексту.** Снимает жёсткость, но
  возвращает риск выдуманной цены. Для прайс-листа из трёх продуктов
  выигрыш не стоит риска.
