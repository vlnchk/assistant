# Решения (ADR)

Каждый файл — одно принятое решение. Формат: `NNNN-краткое-имя.md`.

**Правила:**

1. ADR неизменяем после принятия. Передумали — выпускаем новый ADR
   со статусом «заменяет ADR-NNNN», старому ставим «заменён ADR-NNNN».
   Молча переписывать принятое решение нельзя.
2. Поле **Статус** обязательно и всегда актуально. Именно оно показывает
   разрыв между «решили» и «сделали» — ради него всё и заводилось.
3. Реализовали — вписываем хеш коммита в статус в том же коммите.
4. Ссылаемся на ADR в коде и в сообщениях коммитов: `ADR-0005`.

**Статусы:** `предложено` · `принято, не реализовано` · `реализовано в <коммит>` ·
`заменён ADR-NNNN` · `отвергнуто`
