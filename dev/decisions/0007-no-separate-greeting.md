# ADR-0007. Бот не здоровается отдельной репликой

- **Дата:** 08.09.2026 (записано в ADR 19.09.2026 при расселении бэклога)
- **Статус:** отвергнуто
- **Связан с:** ADR-0002

## Контекст

Клиент здоровается и тут же задаёт вопрос: «Здравствуйте! Какие условия
размещения?». Бот отвечает только на вопрос — приветствие «съедается».
Выглядит суховато, обсуждалось как возможная доработка.

## Решение

**Не делаем.** Бот отвечает одной репликой на ход; приветствие внутри
вопроса игнорируется.

## Последствия

- Первый ответ остаётся суховатым. Принято сознательно.
- Отдельное приветствие возможно только на чистом приветствии без вопроса —
  это уже работает через `send_greeting`.

## Альтернативы, которые отвергли

- **Склеивать приветствие с ответом на вопрос.** Ломает ADR-0002: один tool
  даёт одну каноническую реплику. Потребовало бы либо второго вызова модели,
  либо склейки констант в обход инструментов — то есть отдельного механизма
  ради косметики.
- **Добавить приветствие в начало каждой константы `replies.py`.** Тогда бот
  здоровается на двадцатом сообщении диалога.

Пересматривать, только если появится жалоба от клиентов, а не из ощущения.
