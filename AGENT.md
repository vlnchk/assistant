# AGENT.md

Инструкции для кодовых агентов. Правила общие: Claude Code, Codex, Cursor —
неважно. `CLAUDE.md` — указатель на этот файл.

Telegram-бот-ассистент канала вакансий в образовании: отвечает на FAQ,
показывает свободные даты, бронирует рекламные слоты, собирает заявки на
документы, передаёт сложное менеджеру. Python + aiogram + Gemini + Google Sheets.

## Инварианты

Нарушение любого ломает продукт. Детали — в указанном ADR.

1. **LLM — только роутер.** Текст клиенту — всегда дословная константа из
   `bot/replies.py`. Никогда не сочинять цену, ссылку или условие, даже
   «очевидные». → `dev/decisions/0001-llm-only-router.md`
2. **Один tool на ход, side effect максимум один раз.** Маршрутизация,
   валидация и исполнение разделены — не сливать.
   → `dev/decisions/0002-one-tool-per-turn.md`
3. **Новый интент — это новый инструмент, а не новое правило в промпте.**
   Без инструмента модель возьмёт ближайший существующий: так клиент, покупавший
   вакансию, попал в рекламный календарь.
   → `dev/findings/2026-09-17-paid-vacancy-funnel.md`
4. **Бизнес-правило, которое выражается кодом, в промпт не пишем.** Правило в
   промпте нельзя покрыть юнит-тестом и оно конкурирует с соседними.
   → `dev/decisions/0005-paid-vacancy-goes-to-manager.md`
5. **Прод-инцидент → дословный многоходовой кейс в фикстурах.** Не пересказ:
   пересказ выпрямляет ту двусмысленность, ради которой кейс и заводится.
   Одноходовые кейсы воронки не ловят.
6. **Продукты и запреты по ним** → `dev/decisions/0004-*`, `0005-*`.
   Платная вакансия слот не бронирует; календарь — только для рекламы.

## Опасно

- **`python main.py` локально бьёт по проду.** `.env` содержит боевой
  `TELEGRAM_BOT_TOKEN` и ссылку на живую Google-таблицу. Запуск создаёт второго
  long-polling-потребителя на том же токене — реальные клиенты начнут случайно
  попадать на локальный инстанс, а `book_slot` полезет в живой календарь.
  Локально безопасен только `scripts/eval_assistant.py`: он на
  `DryRunToolExecutor` и внешних записей не делает.
- **Евалы вызывают модель по-настоящему и стоят денег.** Один ход датасета —
  один вызов. Для проверки одной правки гонять подмножество; полный прогон —
  когда правка меняет частый ответ или включает новую логику по нему.
- **Деплой — только по `README.md`, раздел «Обновление бота на VPS».**
  Бэкап на шаге 0 пропускать нельзя, `update.sh` его не делает.

## Команды

```bash
# Юнит-тесты (быстро, модель не вызывают)
.venv/bin/python -m unittest discover -s tests -t .

# Синтаксис
.venv/bin/python -m compileall -q assistant bot llm scripts tests

# Евалы на полном датасете — платно, см. «Опасно»
.venv/bin/python scripts/eval_assistant.py \
  --dataset tests/fixtures/dialog_cases.jsonl --metrics

# Один диалог руками
.venv/bin/python scripts/eval_assistant.py --interactive
```

Деплой на VPS — `README.md`, раздел «🚀 Обновление бота на VPS».

## Карта кода

| Файл | Что там |
|---|---|
| `bot/replies.py` | **Все** тексты клиенту. Единственный источник |
| `bot/handlers.py` | Telegram: rate limit, медиа, forum topics, история |
| `assistant/engine.py` | Ядро хода, от Telegram не зависит |
| `llm/gemini_client.py` | Системный промпт и вызов модели |
| `llm/tools.py` | Инструменты; docstring = маршрутные метаданные |
| `llm/tool_executor.py` | Реестр, валидация, доверенный контекст, dry-run |
| `services/google_sheets.py` | Календарь слотов и задачи по документам |
| `tests/fixtures/dialog_cases.jsonl` | Датасет евалов |

Решение принято — заводим ADR, даже если реализация будет позже: поле
«Статус» существует ровно для того, чтобы разрыв «решили, но не сделали»
было видно. Именно такой разрыв стоил нам инцидента 09.09.2026.

Реализовали — статус ADR и закрытой находки меняем **в том же коммите**.
Этот шаг теряется даже у автора системы, поэтому его сторожит
`tests/test_docs_consistency.py`.

## Конвенции

- Тексты клиенту — только по-русски и только в `bot/replies.py`.
- Docstring'и в `llm/tools.py` — **по-английски**: это маршрутные метаданные
  для модели, клиент их не видит. Не переводить.
- Имена файлов английские, содержание документов русское.
- В этом файле нет ни одной цены и ни одного числа, которое живёт в другом
  файле. Устаревшая цена в двух местах хуже, чем её отсутствие: за ценами —
  в `bot/replies.py`.
- Цен нет и в подсказках модели — docstring'ах `llm/tools.py` и системном
  промпте. Модель выбирает инструмент, цена ей для этого не нужна. Сторожит
  `tests/test_tools.py::NoPricesInRoutingMetadataTests`.
